# Image_multi_effects
Image_multi_effects is a python code that turn an image to a nice .gif with few functions such as :
- Color split effect that use the RGB canals
- Moving image aroung a circle center (Or each RGB canal separately)
- Black lines
- Negative color
- Color inversion
- Glitch
- Randomisation in the previous modules 

The file Image_multi_effects/main_example.py propose an exemple of transformation you could have from any image Img_expl.png (Thanks to [spinband](https://www.spin-band.com)).

# Requirements
Some libraries are used such as :
- [numpy](https://numpy.org/install/)
- [Open CV](https://pypi.org/project/opencv-python/) for image advance transformations
- [matplotlib](https://matplotlib.org/) for plotting
- [imageio](https://pypi.org/project/imageio/) for gif animation
- 'random' for fun and also 'math', 'os', 'sys'
